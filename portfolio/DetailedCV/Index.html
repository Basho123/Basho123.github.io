Flagship achievement: My Vehicle enterprise fleet platform

I have designed and implemented major parts of My Vehicle, an internal fleet-management application used to coordinate the operational lifecycle of company vehicles. The project is a .NET 8 modular application with Oracle persistence and a Vue 3 frontend, and it has given me hands-on experience with complex, stateful business workflows rather than only CRUD-style APIs.


The fleet domain covers Permanent and Pool vehicles, employee vehicle assignments, time-bound reservations, manager and supervisor approval states, cancellation/rejection flows, assignment reversal/vehicle return, visibility rules and overlap/conflict checks. Availability is calculated from authoritative backend state so reservation and assignment changes are reflected consistently across the application.


I also implemented or expanded operational modules for vehicle service history, accidents, registrations and scheduled actions. Maintenance workflows can react to both calendar dates and odometer thresholds, with reminder/notification logic for approaching and overdue actions. Seasonal tyre requirements and other fleet rules are represented as application logic rather than left as manual notes.


The platform integrates vehicle information from a fleet/telemetry source, including latitude/longitude, speed, azimuth, engine state and odometer values. Odometer information is persisted for historical/maintenance purposes and feeds service-related workflows. This gave me practical experience integrating external operational data into an internal business system.


Another subsystem handles automated email ingestion and traffic-infraction processing. Incoming messages are parsed and stored, associated records and files are persisted, status histories are maintained, and scheduled reminders are generated when action is required. Background/scheduled processing is implemented with Hangfire, with timezone-aware behavior for Europe/Skopje where required.


My production responsibilities include designing and modifying REST endpoints, DTOs, validation, domain/business logic and data-access code using C#/.NET, Entity Framework Core and Dapper. I work directly with Oracle SQL, transactions, background processing, integrations and failure cases, while also implementing the Vue 3 client behavior that consumes those APIs.


Security is part of the architecture rather than an afterthought. I have hands-on experience with JWT authentication, role-based authorization and LDAPS-backed enterprise identity integration. Roles such as user, supervisor and administrator are enforced server-side, and workflows that change authoritative state are validated on the backend. This mindset transfers naturally to multiplayer game backend design, where the client cannot be trusted as the source of truth.


I work with Docker, Kubernetes/OpenShift, CI/CD and ArgoCD/GitOps-style deployment workflows. For production diagnostics and observability I use tooling such as Serilog and Elastic APM, tracing behavior across frontend, API, database and external integrations when troubleshooting issues.


Database experience is strongest with Oracle SQL, with additional exposure to MySQL, PostgreSQL and MongoDB/NoSQL fundamentals. I am comfortable with schema design, indexing/query behavior, transactions, consistency, persistence boundaries and data-access patterns, and I can move into adjacent database technologies quickly when the architecture requires it.


For real-time game/backend integration I am actively developing Star Spanner around SignalR/WebSocket-style communication, authoritative state synchronization, prediction/reconciliation concepts and persistent game-state design. The project is intentionally being used to deepen my practical understanding of concurrency, horizontal scaling, service boundaries, load testing and online-game backend architecture.
